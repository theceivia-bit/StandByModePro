# StandBy Mode Pro (Android Jetpack Compose)

Полноценный аналог приложения **StandBy Mode Pro** на Kotlin + Jetpack Compose с настроенной облачной сборкой APK через **GitHub Actions**.

## Что умеет это приложение:
1. **3 стиля часов** (переключаются по нажатию на экран):
   - **Flip Clock** (классические перекидные часы с секундами).
   - **Digital Duo** (крупные часы в стиле iOS StandBy).
   - **Analog Clock** (минималистичные стрелочные часы).
2. **3 встроенных виджета в правой панели**:
   - **Календарь** на текущий месяц на русском языке с выделением сегодняшнего дня.
   - **Фокус-таймер (Pomodoro)** на 25 минут с управлением Старт/Пауза/Сброс.
   - **Монитор батареи и датчика освещенности** (показывает % заряда, статус зарядки и уровень света в люксах).
3. **Умный ночной режим (Night Red Mode)**:
   - Считывает показания физического датчика освещенности смартфона (`Sensor.TYPE_LIGHT`).
   - В темноте (< 8 люкс) автоматически перекрашивает интерфейс в мягкий темно-красный цвет, который не слепит глаза ночью. Также можно включить вручную кнопкой на верхней панели.
4. **Защита OLED/AMOLED от выгорания (Burn-in Protection)**:
   - Каждую минуту интерфейс незаметно сдвигается на случайное значение в пределах `±12 px` по осям X и Y.
5. **Автоматический запуск при зарядке**:
   - Встроенный `PowerConnectionReceiver` перехватывает подключение кабеля или беспроводной зарядки (`ACTION_POWER_CONNECTED`) и запускает часы поверх экрана блокировки, а при отключении питания — автоматически закрывает их.

## Как получить готовый `.apk` файл за 3 минуты (без установки программ на ПК):

1. Зайдите на сайт [github.com](https://github.com/) (войдите в аккаунт или зарегистрируйтесь).
2. Нажмите **New repository** (кнопка `+` в правом верхнем углу), назовите его `StandByModePro` и нажмите **Create repository**.
3. На странице созданного репозитория нажмите ссылку **uploading an existing file**.
4. Распакуйте скачанный архив `StandByModePro_Android_GitHub_Project.zip` на своем компьютере или телефоне и **перетащите все папки и файлы** (`app`, `.github`, `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`) в окно браузера.
   > **Важно:** Убедитесь, что скрытая папка `.github/workflows/build-apk.yml` тоже загрузилась (если ваш проводник скрывает папки с точкой, включите показ скрытых файлов или создайте файл `.github/workflows/build-apk.yml` через кнопку *Add file -> Create new file* на GitHub).
5. Нажмите зеленую кнопку **Commit changes** внизу страницы.
6. Перейдите на вкладку **Actions** вверху вашего репозитория. Вы увидите запущенный процесс **Build StandBy Mode Pro APK**.
7. Подождите 2–3 минуты, пока значок станет зеленым ✅, кликните по завершенной сборке и внизу в разделе **Artifacts** скачайте готовый архив **`StandByModePro-Debug-APK`**, внутри которого лежит ваш установочный файл **`app-debug.apk`**.
